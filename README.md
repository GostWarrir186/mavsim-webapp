# Mavsim — страницы Telegram WebApp

Форма заказа клиента, кабинет курьера, панель и статистика менеджера для ботов
доставки Mavsimi Rason. Только статические HTML/CSS, отдаются через GitHub Pages.
Данные приходят в URL от бота; ключей и секретов здесь нет и быть не должно.

Код ботов — в отдельном приватном репозитории.
